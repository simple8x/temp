# G3/G4 geometry algorithm repair (v2)

## What changed
- Added geometric relation classes: ENDPOINT_ENDPOINT, T, CROSSING, OVERLAP, DEGENERATE, and DISJOINT.
- Every geometric relation is a candidate first, never an electrical connection by itself.
- A verified join requires independently supported WIRE roles and either same-source-PDF-path continuity at a shared endpoint or a separately reviewed junction-dot record at the intersection.
- OCR labels cannot attach by nearest-distance. Attachment requires an explicit review record, a verified wire role, and the anchor lying on the segment.
- Pin anchors require a verified symbol-template identifier, pin number, and source evidence record.
- Page boundaries are hard boundaries. Unknown classifications remain UNKNOWN.

## Regression evidence
python -m unittest -v test_g3_g4_geometry.py: 14 tests PASS in the local test run. Coverage includes endpoint, T-junction, crossing, dot evidence, overlap, degenerate geometry, near-parallel non-joins, cross-page isolation, pin-template gating, and label attachment gating.

## Scope / release decision
This is a reusable classifier and fail-closed evidence gate. It does not retroactively classify the 70,278 extracted primitives as wires, does not manufacture junction evidence, and does not claim the QI9 PDF's full electrical topology is complete. Existing G3/G4 status remains BLOCKED until source PDF primitives are reviewed/classified and the classifier is integrated against the actual page-6 extraction. No netlist is generated by this patch.
