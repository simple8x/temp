# Gemini Autonomous Engineering Skill

Skill ID: `autonomous-engineering-pdf2kicad-aios`

This skill combines:
1. Repository investigation, root-cause repair, regression testing, and evidence-based delivery.
2. PDF2KiCad vector schematic recovery, netlist reconstruction, and G3/G4 electrical verification.
3. AIOS authority, durable effects, receipts, reconciliation, and recovery.

## Contents
- `SKILL.md` — entry point and mandatory operating rules.
- `workflows/pdf2kicad.md` — PDF extraction and electrical verification workflow.
- `workflows/aios-authority.md` — authority and durable execution workflow.
- `schemas/evidence-receipt.schema.json` — receipt data contract.
- `schemas/verification-report.schema.json` — verification report data contract.
- `tests/acceptance-checklist.md` — manual acceptance criteria.

## Install
Copy the folder `autonomous-engineering-pdf2kicad-aios` into the skills directory supported by your installed Gemini client/agent, then enable or discover the skill using that client's documented skill mechanism. The exact discovery path depends on the Gemini product and version; this repository change does not install it into a Gemini account automatically.

## Safety
The skill does not grant credentials or authority. It requires explicit user authorization for consequential external actions and never treats missing evidence as PASS.
